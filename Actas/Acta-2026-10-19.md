- Objetivo:
    Organizar las actividades correspondientes a la primera evaluación del proyecto Peluditos Pet Chile, distribuir las responsabilidades entre los integrantes y definir los próximos pasos para el desarrollo de la solución propuesta.

## Avances
Se revisaron los requerimientos de la primera evaluación y los acuerdos establecidos en la reunión anterior.

Se analizó nuevamente la problemática del emprendimiento, principalmente la falta de un registro centralizado de clientes potenciales y la ausencia de un sistema de seguimiento de consultas y futuras compras.

Se acordó continuar con la propuesta de una plataforma de gestión que permita registrar clientes, administrar consultas y realizar seguimientos de manera organizada.
También se revisaron las tecnologías solicitadas para el desarrollo del proyecto, considerando el uso de BPMN, Flowable, servicios web en Java y un repositorio compartido en GitHub.

## Acuerdos y decisiones
Se acordó dividir el trabajo en tres áreas principales para facilitar el desarrollo y permitir que cada integrante avance en una parte del proyecto.

## Bloqueos y dificultades:
Se identificó como principal dificultad la falta de experiencia práctica con Flowable y la integración de servicios web en Java.
También se reconoció la necesidad de coordinar el desarrollo de los distintos componentes para asegurar que los diagramas BPMN, el servicio web y el proceso ejecutable sean compatibles entre sí.

## Logros y próximos pasos:
Se logró establecer una distribución de responsabilidades entre los integrantes, permitiendo organizar el desarrollo del proyecto.
Como próximos pasos, se acordó avanzar en el modelado BPMN, el desarrollo del servicio web y la configuración del proceso en Flowable.
Una vez completadas estas actividades, se realizarán las pruebas de integración y se reunirán las evidencias correspondientes para la primera evaluación.

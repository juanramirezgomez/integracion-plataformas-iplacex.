## Cambios realizados

- Se ordenó el repositorio por componentes. La pantalla quedó en `Interfaz/`, el worker en `External-Workers/`, el arranque del motor en `Flowable/` y las pruebas en `Pruebas/Servicio-Java/` y `Pruebas/Recorridos/`. Se retiraron las carpetas genéricas `Proyecto-2/` y `Proyecto-3/`. Los tags siguen identificando las versiones ya entregadas.
- Se actualizaron el [README](../README.md), los comandos de ejecución y el [diagrama de la arquitectura local](../Arquitectura/modelo-arquitectura.md). Se agregó un enlace directo al worker y a su evidencia.
- Se actualizó el [BPMN de consultas y prospectos](../BPMN/TO-BE.bpmn). Cuando se registra una compra, el worker actualiza el estado en Java y Flowable cierra la consulta. Si no se concreta una compra, el proceso sigue por la ruta de seguimiento.
- Se agregó el [BPMN de oportunidades de recompra](../BPMN/Oportunidades-Recompra.bpmn), que puede empezar por una fecha o campaña para un cliente existente. Se incluyeron las imágenes de [consultas](../BPMN/TO-BE.png) y [recompra](../BPMN/Oportunidades-Recompra.png), y se actualizó la [justificación de los modelos](../BPMN/justificacion-TO-BE.md).

## Pruebas realizadas

- En Flowable OSS 8 se repitieron por API los recorridos de consulta con compra y sin compra. Se comprobó que el worker tomó las tareas externas, llamó al servicio Java y devolvió el resultado a Flowable.
- Se iniciaron por API dos oportunidades para un cliente de prueba registrado directamente en Java, sin una consulta previa. La oportunidad por cumpleaños terminó con un contacto registrado y la campaña de Navidad se cerró sin contacto. [Ver resultados de recompra](../Pruebas/Recorridos/resultados-recompra.json).
